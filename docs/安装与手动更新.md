# DCS-SRS 中文手动更新版：安装与更新

首次安装或从其他版本迁入：下载本次 Release 中的 `DCS-SimpleRadioStandalone-版本-cn.修订号.zip`，完整解压到临时目录，运行根目录 `Installer.exe`。核对安装目标及 DCS 脚本选项后安装；覆盖前备份配置。不确定旧目录时选择独立目录。安装目标不能是磁盘根目录、安装包目录或其父子目录。

GitHub 自动生成的 Source code ZIP/TAR 是源码，不能安装。包内 `SRS-AutoUpdater.exe` 必须保留供客户端按钮调用；不要单独下载它来首次安装或迁入，也不要用它替换其他版本目录中的文件。

Windows 图形组件需要 .NET 10 Desktop Runtime x64；命令行服务器 Windows/Linux x64 自包含。汉化程序未签名，未打包微软雅黑字体。

启动不检查、不执行更新，不弹更新通知。在“高级设置 → 全局设置 → 软件更新（仅手动）”选择中文源或英文源，查看来源、版本和说明后确认。下载完成只打开安装器，仍须核对目录及脚本选项，并自行退出目标目录中的 SRS。中文安装器不会强制结束进程。

中文更新默认传递发起客户端所在安装目录，优先于历史注册表记录；手工运行安装器时可能预填旧记录，必须核对。中文修订号通过安装目录的 release-manifest.json 识别，基础协议版本仍为 2.4.1.0。更换修订版会更新清单。

切换英文源将覆盖汉化和本项目的手动更新行为，原版可能恢复自动更新。英文安装器保留原作者行为，可能结束其他 SRS 实例、读取旧目录；先退出所有 SRS，并手动核对安装位置。切换回中文应下载中文完整 ZIP 安装，不能依赖英文界面保留中文源按钮。

关闭下载窗口或取消会取消下载；网络失败、压缩包错误或缺少安装器时不启动安装。DCS 仍运行时退出此次安装启动，可关闭 DCS 后重试。安装已开始后的文件复制不提供事务回滚；保留原安装包及配置备份，失败后重新安装。

验证范围见本次审查修复记录；不代表 DCS 接入、真实语音、覆盖安装或跨源切换已实际验收。

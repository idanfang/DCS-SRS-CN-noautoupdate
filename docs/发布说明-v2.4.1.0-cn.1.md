# DCS-SRS 中文手动更新版 2.4.1.0 / CN

基于原作者 2.4.1.0 英文源码，现有中文项目用于参考译文。客户端、服务器、安装器和更新器提供中文界面；默认使用系统已安装的微软雅黑，未分发字体文件。

客户端标题：**DCS-SRS 客户端 - 2.4.1.0 - CN（手动更新版）**。

启动时不检查或执行自动更新，不弹出自动更新提示。在“高级设置 → 全局设置 → 软件更新（仅手动）”主动选择中文手动更新版或原作者英文原版。更新英文原版会覆盖本分支汉化和手动更新行为。

## 下载与安装

下载 `DCS-SimpleRadioStandalone-2.4.1.0-cn.1.zip`，完整解压后运行根目录 `Installer.exe`。这是包含安装器、客户端、服务器、外部音频组件及 DCS 脚本的安装包；不要将旧便携测试 ZIP 当作此安装包。

Windows x64 组件需要 Microsoft .NET 10 Desktop Runtime x64。Windows / Linux 命令行服务器为各自 x64 的自包含发行。重新编译的汉化可执行文件未签名；不使用原作者签名证书。

`SRS-AutoUpdater.exe` 是完整 ZIP 内供本版客户端按钮调用的内部组件。它不能独立完成首次安装或从旧版迁入，也不应下载后替换旧版更新器。首次安装和迁入均下载完整 ZIP，并运行 Installer.exe 核对目录。GitHub 自动生成的 Source code ZIP/TAR 也不是安装包。对应手动更新标签为 `v2.4.1.0-cn.1`，内部协议与软件版本仍为 `2.4.1.0`。

## 使用范围和已知限制

本发行面向正常安装、正常使用的单套 SRS 升级场景。安装和升级前关闭 DCS，并自行退出需要保留运行的其他 SRS 实例。

继承的安装更新流程按进程名结束 SRS 进程，并从已有配置推断安装位置：

- **P1：** 多套共存时可能结束其他目录的 SRS 进程。
- **P2：** 手动搬移目录或多套共存时，更新可能覆盖配置记录指向的正式目录。

上述问题本版未修复；多套共存或手动搬目录时应手动下载完整包并核对安装目标，不将本版更新器视为隔离安装工具。

验证：用户实际查看通过界面、微软雅黑和窗口标题；已有公共组件测试与发布前构建、包布局及完整性校验通过。本次没有在用户 PC 覆盖安装，没有部署 DCS 脚本或执行联机语音、真实更新安装全矩阵验收。

本汉化版不会跟随英文原版自动同步发布。如原版有重大更新，请联系维护者。

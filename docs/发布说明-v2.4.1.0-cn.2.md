# DCS-SRS 2.4.1.0 CN 中文手动更新版 · cn.2

基于英文上游 2.4.1.0 源码，中文译文参考中文项目。基础软件/协议版本仍为 2.4.1.0，中文修订标签为 v2.4.1.0-cn.2。

## 下载和安装

下载 `DCS-SimpleRadioStandalone-2.4.1.0-cn.2.zip`，完整解压到临时目录，运行根目录 `Installer.exe`。这是 GitHub Actions 从本标签源码编译并组装的完整安装包，可用于首次安装、从其他版本迁入以及升级。安装前退出目标目录里的 SRS、关闭 DCS、备份配置，并核对安装目标与 DCS 脚本选项。

`SHA256SUMS.txt` 提供完整 ZIP 的 SHA256。GitHub 自动生成的 Source code ZIP/TAR 是源码，不是安装包。`SRS-AutoUpdater.exe` 保留在完整 ZIP 内供客户端按钮调用，不作为独立公开附件，不能单独首次安装或迁入。

Windows 图形组件需要 Microsoft .NET 10 Desktop Runtime x64。Windows/Linux x64 命令行服务器自包含。汉化可执行文件未签名；微软雅黑仅引用系统已安装字体，没有打包字体文件。

## 本次修复

- 中文安装器和更新器不再强制结束 SRS 进程；目标目录内组件仍运行时提示自行退出，其他目录实例不被强制关闭。
- 中文手动更新传递当前安装目录，优先于历史配置；安装器始终让用户核对目录和脚本选项，再确认安装。
- 拒绝磁盘根目录及与安装包目录相同或存在父子关系的安装目标，避免清理掉安装来源。
- 成功复制程序后安装实际中文修订标签清单，正确识别后续修订；坏清单不报告“已是最新”。
- 中文安装包按标签精确选取，启动安装前核对 SHA256；修复取消请求后继续下载、DCS 循环提示和安装器启动错误处理。
- 云端打包支持同基础版本的后续中文修订，核实不可变标签源码，拒绝旧产物混入或替换已有安装附件。

启动时仍不检查、不执行更新，不弹出更新提示。手动更新位于“高级设置 → 全局设置 → 软件更新（仅手动）”，保留中文源和英文原版源。

切换英文原版会覆盖汉化和本项目的手动更新行为，可能恢复原版自动更新。英文安装器保留原作者进程和目录行为：先退出所有 SRS，并核对安装目录。切回中文请下载中文完整 ZIP。

## 验证与限制

本地客户端、安装器、更新器构建成功；公共组件测试 10/10、打包前置回归 5/5 通过。云端流程执行公共测试、七组件编译、固定上游资源摘要校验、单文件依赖、完整 ZIP 和校验文件检查，构建证据保留在 Actions。

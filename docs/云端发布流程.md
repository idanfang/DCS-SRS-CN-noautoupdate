# 中文修订版云端打包流程

当前打包工具支持基础版本 2.4.1.0 的 `v2.4.1.0-cn.N` 修订标签。更换基础版本必须先核验英文源码与官方资源 ZIP 来源、摘要和组件版本，再调整固定来源；不能通过改标签绕过来源核验。

1. 提交已验证的源码、打包工具及安装说明；为新修订建立不可变标签。不得移动 cn.1 或其他已发布标签。
2. 为同一标签创建草稿 Release。不要提前发布没有完整安装 ZIP 的 Release；客户端仅查稳定公开发行。
3. 从含最新打包工具的 localize-2.4.1.0 分支手动运行 Chinese installer release，输入同一标签。标签推送触发也要求 Release 已存在；若触发时不存在，它会提前停止，可在草稿就绪后手动重跑。
4. 流程只读核实 Release 附件尚未存在，检出标签源码，检查 HEAD 与标签提交一致、工作区干净、源码在构建期间稳定；运行工具离线回归和公共测试；构建七个组件；核验固定上游资源 ZIP 摘要；生成并核验完整安装 ZIP、单文件依赖、字体禁止项和 SHA256SUMS。
5. 上传附件仅为完整安装 ZIP 和 SHA256SUMS.txt；SRS-AutoUpdater.exe 必须在 ZIP 根目录，不能作为单独公开安装附件。保留 Actions 构建证据。
6. 人工核对草稿附件和说明后再发布。上传不使用 --clobber，已有安装附件时流程提前拒绝。发现已公开包存在问题，用新修订标签发布，不覆盖原包。

首次完整安装、迁入、后续手动升级与英文切换说明见《安装与手动更新》。发布说明需要注明 .NET 10 Desktop x64、未签名、实际验证和未验证范围，说明完整 ZIP 与自动源码归档的区别。

现有 cn.1 公开 Release 的独立更新器附件和旧说明尚未调整。本次仅修改本地代码；若要移除独立附件，应先获得用户对该具体远端操作的授权，不删除 ZIP 内的更新器，也不替换 cn.1 安装包。

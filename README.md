# DCS-SRS-CN-noautoupdate

基于原作者 **2.4.1.0** 源码的中文手动更新版，为中国 DCS 用户提供完整中文界面。中文词条参考 [omltcat/DCS-SRS-CN](https://github.com/omltcat/DCS-SRS-CN)，保留 2.4.1.0 的功能实现。

本版本最大的区别：**启动时不检查或执行自动更新，也不弹出更新提示**。用户可以在“高级设置 → 全局设置 → 软件更新（仅手动）”中主动选择：

- **更新中文手动更新版**：查询 [本项目发布页](https://github.com/idanfang/DCS-SRS-CN-noautoupdate/releases)，确认后安装本分支的发行包。
- **更新英文原版**：查询 [原作者发布页](https://github.com/ciribob/DCS-SimpleRadioStandalone/releases)，确认后安装英文原版。此操作会覆盖汉化和本项目的手动更新功能，原版可能恢复自动更新。

本汉化版不会跟随英文原版同步升级。如原版有重大更新，请联系维护者。

- [维护者 B 站主页](https://space.bilibili.com/7317347)
- QQ 群：**1006786675**
- [中文翻译修订对照](docs/翻译修订对照.md)

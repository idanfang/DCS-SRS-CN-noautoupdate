# DCS-SRS-CN-noautoupdate

DCS-SRS 中文手动更新版，面向中国用户。沿用原软件界面和已有汉化资源。

**最大的区别：禁用自动检查和自动升级。只有用户在原有通用设置中点击“检查更新”，并确认安装，才会进行升级操作。**

更新来源可选择：

- 本项目中文手动更新版：[发布页](https://github.com/idanfang/DCS-SRS-CN-noautoupdate/releases)。
- 原作者英文原版：[发布页](https://github.com/ciribob/DCS-SimpleRadioStandalone/releases)。安装原版会覆盖汉化和本项目的手动更新改动，可能恢复原版自动更新行为。
